# 向下修正信号：接入说明

**日期**：2026-10-20
**状态**：已接入 `earnings_watch.py`，端到端验收通过

---

## 一、这个信号是什么

**同一股票、同一报告期，第二次公告的增速低于第一次公告。**

被回测证伪过的 A1/A2 分组不同，这一点有统计支撑：

| 口径 | 向下修正 | 首次公告（对照） |
|---|---|---|
| 20日超额 | **−2.40pp** | +0.31pp |
| t 值 | **−2.77** | +3.81 |
| 胜率 | 38.0% | 43.6% |
| 样本 | 421 | 30,719 |
| 分年符号 | **7/8 年为负** | — |
| 同日中性化后 | **−1.85pp（t=−2.42）** | +0.02（t=0.26） |

扣 16bp 成本，基准中证1000，2019–2026。

**用途限定：只做减仓/回避，不做空。** A股融券成本高、券源少，负向信号的实际用法是"持仓股出现时退出"。

---

## 二、怎么用

正常每日运行（计划任务会自动跑），输出里多两个分组：

```
【X 向下修正（回避）】1 只   已回测：20日超额 -2.40pp、t=-2.77、胜率38%（n=421）
  代码      名称            增速%    p20    p60   p120    距高%    今日%      PE    市值亿  负面
  --------------------------------------------------------------------------------------
  600187  *ST国中          114.5    5.9    2.0    1.4   -36.7    -5.9     亏损      18     0

【Y 向上修正（不显著）】...   已回测：20日超额 +0.94pp、t=0.85（不显著）
```

**优先级高于位置分组**：一只股票如果是向下修正，即使它同时满足 A2（高增+低位），也归入 X 而不是 A2。

## 三、技术实现（关键坑）

### 为什么必须用本地台账

**Tushare 对同一 (股票, 报告期) 只保留最新一条。** 这一点我实测确认过：

| 拉取方式 | 301569.SZ / 20260930 拿到几条 |
|---|---|
| `period=20260930` | **1 条**（只有修正后的 20261009） |
| `start_date=20260702&end_date=20261009` | **1 条**（同上） |
| `start_date=20260701&end_date=20261020` | **1 条**（同上） |

首次公告 20260917 那条**在任何窗口下都拿不到**。

所以：
- `shift(1)` 后 `prev_g` 恒为 NaN → **修正识别永远返回空**
- 曾尝试用 `first_ann_date < ann_date` 判断，但只能知道"发生过修正"，**拿不到修正前的基线**，算不出 `delta` 方向

**解法：本地台账。**

```
earnings_watch/forecast_ledger.csv   47,856 行
```

每次运行把当期公告 append 进台账，按 `(ts_code, end_date, ann_date)` 去重。
台账累积了 2019-01 至今全部 1,501 条修正记录（向上 491 / 向下 798），基线永久保留。

### 台账从哪来的

用之前拉的全量历史 `scratch/fc_hist/forecast_all.csv`（50,015 行，按季度分段拉取）初始化。
**该文件保留了修正记录，因为它是按季度窗口分段拉的**——季度窗口内同一股票同一报告期的多条公告会被保留。

> 注意：这个"区间能保留多条"的行为不具备跨窗口稳定性。
> 实测 2024Q1 窗口有 88 组内>=2 条，2023 年报 period= 有 96 组，
> 但 2026Q3 窗口的 2,038 行里只有 29 组。
> **结论：不能依赖接口返回多条，必须靠台账累积。**

### 三个修正过的缺陷

| 缺陷 | 现象 | 修复 |
|---|---|---|
| 用 `period=` 拉取 | 修正识别恒为空 | 改用台账 |
| 窗口基准用 `datetime.now()` | `--date=历史日` 时窗口错位，拿不到该日修正 | 改用 `date` 参数 |
| 分组函数先判位置 | 向下修正的股票被归入 A2，信号被淹没 | 修正判定提到位置判定之前 |

## 五、不可忽视的局限

1. **样本只有 421 个向下修正**，2025 年出现过反向（+5.98pp，n=45）。**极端行情下可能失效。**
2. **无法做空**。A股负向信号只能用于减仓，实际价值取决于你恰好持有该股。
3. **一年约 50 次**，命中率取决于你的持仓与全市场的重叠。
4. **台账依赖每日运行**。如果程序停跑，台账会出现断层，修正识别会漏。建议保留计划任务的三个时点。
