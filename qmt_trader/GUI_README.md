## 六个按钮

### ① 环境体检

检查项：
- Python 依赖（pandas / numpy / tushare / xtquant）
- Tushare token 与 API 连通性
- miniQMT 连接、账户资产、持仓
- 配置摘要与购买力口径

**启动时自动执行一次。**

### ② 盘前准备

- 从 Tushare 拉取最新市值数据
- 构建标的池（30–80 亿小市值）
- 检查市场择时
- 输出今日动作建议

**结果写入顶部「市场状态」栏。**

### ③ 扫描信号

两个范围选项：

| 选项 | 耗时 | 说明 |
|---|---|---|
| 本地缓存(快) | ~15 秒 | 只扫已缓存的标的 |
| 全部标的(慢) | 数分钟 | 扫全部标的池（受 Tushare 限频） |

**「忽略择时」勾选框**：勾上后仅看个股形态，不受市场择时限制（**观察用，不是交易信号**）。

结果填入三个标签页：

| 标签页 | 内容 |
|---|---|
| **买入信号** | 6 个条件全满足 |
| **接近满足** | 满足 5/6 条件（观察池） |
| **卖出信号** | 持仓触发的止盈/止损 |

**点击任意行 → 右侧显示该标的 K 线图与条件明细。**

### ④ 执行建仓

按买入信号下单。

**默认演练模式**（不下单）。要实际下单需勾选工具栏的 **LIVE** 框，会有二次确认弹窗。

### ⑤ 持仓监控

检查所有持仓是否触发：
- 触及布林上轨 → 止盈
- 跌破止损价 → 止损
- 超过最大持有天数 → 超时离场

### ⑥ 账户查询

- 资产摘要（总资产/可用/市值/理财占用/购买力）
- 持仓明细（成本、市值、浮动盈亏）
- 当日委托与成交
- 卖出信号标签页自动填充

## K线图

显示内容：
- **蜡烛图**：红涨绿跌
- **布林带**：上轨（橙）/ 中轨（蓝）/ 下轨（绿）
- **MA60**：紫色虚线
- **买入信号**：黄色三角
- **触及下轨**：绿色圆点
- **成交量**：底部柱状图

**「显示信号」勾选框**可切换信号标记显示。

## 安全机制

| 机制 | 说明 |
|---|---|
| **默认演练** | 不勾 LIVE 时不会真实下单 |
| **LIVE 二次确认** | 勾选后下单前弹窗确认 |
| **模式门禁** | 后端 simulation 模式抛 PermissionError |
| **日志脱敏** | token/账号自动打码 |

## 常见问题

### Q: 点击扫描后一直没反应

看右下角进度条和日志。全池扫描受 Tushare 限频（约 0.35 秒/只）影响，2168 只约需 10+ 分钟。**建议用「本地缓存(快)」模式。**

### Q: 一个信号都没有

**这是正常的。** 策略要求 6 个条件同时满足，且市场择时（中证1000 60日 < −20%）是硬门槛。

当前（2026-10-14）市场 60日 −12.87%，**未通过 → 空仓等待**。

### Q: 勾了「忽略择时」还是没有信号

因为还有 5 个个股条件。最重要的是：
- **连续触轨 ≥2 天**（通过率仅 6.9%）
- **月线趋势向上**（通过率 30.5%）

看「接近满足」标签页能看到 5/6 条件的标的。

### Q: K线图不显示

点击信号列表或持仓表的任意一行即可加载。首次加载需从 Tushare 拉取数据（约 2–5 秒）。

### Q: 账户显示「可用资金 0」

余额理财占用了资金。GUI 已按 `auto` 口径解析购买力（回退到总资产）。详见主 README 的 Q5。

## 技术说明

| 组件 | 技术 |
|---|---|
| GUI 框架 | PySide6 (Qt6) |
| 图表 | matplotlib + QtAgg |
| 后台任务 | QThread（不阻塞界面） |
| 样式 | 深色主题 QSS |

**所有耗时操作都在后台线程执行**，界面不会卡死。任务运行时按钮会禁用，防止重复触发。
