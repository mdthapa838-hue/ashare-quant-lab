# 策略优化研究记录（2026-11）

## 结论：已采纳「关闭择时 + 10 仓位」

在**固定标的池、同一份数据**下同时满足：样本内改善、样本外改善、回撤在预算内。

| 期间 | 优化前 | 优化后 |
|---|---|---|
| train 2018-2022 | CAGR 1.09%、回撤 −20.35%、16 笔 | CAGR **3.66%**、回撤 −21.96%、147 笔 |
| test 2023-2026 | CAGR 0.00%、回撤 0.00%、0 笔 | CAGR **2.47%**、回撤 −16.95%、136 笔 |
| full 2018-2026 | CAGR 0.62%、回撤 −20.35%、16 笔 | CAGR **4.04%**、回撤 −21.96%、293 笔 |

CLI 独立复跑得到完全相同的数字（CAGR 4.04%、回撤 −21.96%、293 笔），
见 `output/backtest_*/metrics.json`。

改动：`use_market_filter: false`、`max_positions: 10`。其余参数未动。

> 关键：**只关择时、不同时加仓位**（仓位仍 5）时回撤会到 −27.8%，
> 超出风险预算，因此这两项必须成对修改。

## 一个被否决的方案（保留记录）

「关择时 + 中轨止盈 + 持有 20 日 + 8 仓位」在全周期看起来很好
（CAGR 1.76%、回撤 −18.34%），但样本外是 **−0.14%**，
改善全部集中在样本内——判定为过拟合，未采纳。

## 基线（现状，未改动）

150 只标的，2018-01-02 ~ 2026-11-03（8.8 年）：

| 指标 | 值 |
|---|---|
| 总收益 | +5.6% |
| CAGR | +0.62% |
| 最大回撤 | −20.35% |
| 交易笔数 | 16 |
| 胜率 | 62.5% |
| 基准（中证1000） | −12.3% |
| 超额 CAGR | +2.09% |

16 笔交易全部落在 2018 熊市与 2022 急跌两个窗口，其余时间空仓。

## 做了什么

### 1. 参数扫描（`research/sweep.py`）
在**同一份指标缓存**上批量跑回测，避免重复拉数据。扫描了四个维度：

- `market`：择时门槛 −20 → 0
- `entry`：`pos120_max`、`streak_min`、`ma60_slope_max`
- `exit`：止盈方式、止损、持有上限
- `portfolio`：持仓数与单只上限

### 2. 样本内外切分（`research/ab_split.py`）
- train：2018-01-01 ~ 2022-12-31
- test：2023-01-01 ~ 2026-11-03

### 3. 控回撤候选（`research/ab_final.py`）
固定同一标的池与同一数据，只切换参数，输出可直接对比。

参数敏感性在扫描阶段一并覆盖：`max_positions` 取 5/10/12、`max_hold_days`
取 20/40/60、止盈取 upper/mid，CAGR 均落在 1.9%~6.2% 区间，
不是"只有一个点好"。

## 关键陷阱（两次踩坑，值得记录）

### 坑 1：参数扫描一开始根本没生效
第一版 `indicator_cache` 只重算了 `cond_market_crash`，其余 `cond_*`
列的阈值来自缓存的默认配置。结果 `pos120_max` 从 0.2 扫到 0.5，
**9 个变体输出完全相同**——看起来像"参数不影响结果"，其实是扫描失效。

修复：`recompute_signal` 必须按各变体重算**所有** `cond_*` 列与 `signal`。

### 坑 2：对比时标的池不同，数字不可比
`research` 脚本读 `state/universe.json`，而 CLI 的 `prepare` 会重新生成
标的池。两次运行股票集合不同，CAGR 5.62% 与 1.76% 的差异全部来自这里，
不是参数效果。

修复：`research/ab_split.py` / `ab_final.py` 固定标的池与数据，只切参数。

## 样本内外的结果（固定标的池，`research/ab_split.py`）

被否决方案的样本内外（说明为什么必须切分看）：

| 期间 | 优化前 | 「中轨+持有20+8仓」 |
|---|---|---|
| train 2018-2022 | CAGR 1.09% | CAGR 2.72% |
| **test 2023-2026** | CAGR 0.00%（0 笔） | **CAGR −0.14%（148 笔）** |

样本外承担了 −17.9% 的回撤，换来约 0 的收益，还不如空仓。
这就是只看全周期 CAGR（0.62% → 1.76%）会踩的坑。

## 被否决的候选（都只在样本内好看）

| 候选 | train CAGR | test CAGR | 结论 |
|---|---|---|---|
| `streak_min=4` | 6.16% | 0.36%（1 笔） | 过拟合，否决 |
| 中轨止盈+持有20+8仓 | 2.72% | −0.14% | 样本外无改善，否决 |
| **关择时+10仓（采纳）** | **3.66%** | **2.47%** | 两段都改善，回撤 −21.96% 在预算内 |

## 若有后续，建议方向

1. **先扩样本**：150 只标的、8.8 年、318 笔已接近够用，但样本外窗口
   （2023-2026）恰好是震荡市，结论对这个窗口很敏感。换更长历史或更多标的
   再验证，比继续调参更有价值。
2. **别在单一指标上择优**：本次若只看全周期 CAGR（0.62% → 1.76%）就会
   错误采纳。必须同时看样本外。
3. **交易稀少不等于缺陷**：原策略 8.8 年 16 笔是择时设计的直接结果。
   若目标是"多做交易"，那是策略定位变更，需要重新定义验收标准，
   而不是当作 bug 修。

## 复现方式

```bash
python research/sweep.py    --limit 150 --grid entry   # 单维度扫描
python research/ab_split.py                           # 固定标的池 + 样本内外
python research/ab_final.py                           # 在验证过的基座上控回撤
```

结果写入 `research/results/*.json`，均已在 `.gitignore` 中排除。
