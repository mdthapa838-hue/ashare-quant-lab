# 布林带下轨反弹策略

## 一、这是什么

一个**已实现并验证**的 A 股小盘股交易策略系统。核心逻辑：

> 在「**长期趋势向上 + 中期下跌 + 短期超卖**」的位置买入布林带下轨，
> 持有至布林带上轨或止损离场。

---

## 二、策略逻辑（为什么这样设计）

| 层级 | 条件 | 作用 | 实证贡献 |
|---|---|---|---|
| **择时** | 中证2000 60日收益 < -20% | 只在市场急跌时出手 | +10.38pct（最强） |
| **长期趋势** | 月线收盘 > 月线MA6 或 MA6向上 | 确保大趋势未坏 | +5.90pct |
| **中期趋势** | MA60的20日斜率 < -1% | 确保已跌透 | 基础条件 |
| **相对位置** | 120日区间分位 < 0.30 | 赔率改善 | 基础条件 |
| **短期信号** | 连续≥2天收在布林带下轨 | 抛压衰竭 | 基础条件 |

**已测试但未采用的条件**（避免添加噪音）：

| 条件 | 测试结论 |
|---|---|
| J值 < 13 | 无边际贡献（+0.00pct），与超卖条件重复 |
| 周线不走跌 | 仅 +0.33pct，不值得增加条件 |
| 热门赛道（行业20日>0） | **反向**（-2.99pct），超跌反弹不追热点 |

## 八、关键风险（务必阅读）

### 8.1 幸存者偏差（最严重）

回测使用**当前存续**的 520 只标的回看历史。**已退市、长期停牌的标的未纳入。**

而本策略专买「低位 + 下跌趋势」的股票 —— **正是退市风险最高的一类**。

**建议：把回测收益打 6-8 折来评估。**

### 8.2 样本局限

- 标的池为 30-80 亿小盘股，**不可外推到大盘股或全市场**
- 使用日线前复权数据，未考虑分红再投资、停牌期间的处理
- 成本按单边 0.15% 近似，小盘股实际滑点可能更高

### 8.3 容量限制

年交易约 30 笔，单笔需在 20 日均额 2000 万以上的股票上操作。
**资金规模建议不超过 500 万**，否则冲击成本显著。

### 8.4 择时的双刃剑

「完整策略」（带择时）CAGR 仅 9.18%，因为择时把机会压到极少。
**「无择时」版本收益高但需要承受更多交易和更高波动。**

### 8.5 未做的验证

- 未做完整 walk-forward（仅时间切分）
- 未做多重检验校正
- 未接入实时财务数据（无退市风险预警）

## 九、参数说明（config 文件）

```yaml
entry:
  pos120_max: 0.30          # 相对位置上限
  streak_min: 2             # 连续触轨最少天数
  ma60_slope_max: -0.01     # MA60斜率上限
  use_monthly_filter: true  # 月线过滤（推荐开启）
  use_market_filter: true   # 择时（推荐开启）
  market_ret_max: -20.0     # 市场60日收益上限
  use_j_filter: false       # J值（建议关闭）
  use_weekly_filter: false  # 周线（建议关闭）

exit:
  take_profit: upper        # 上轨止盈（不要用mid）
  stop_loss_pct: -0.12      # 止损
  max_hold_days: 60         # 最长持有

portfolio:
  max_positions: 5          # 最多持仓
  max_position_pct: 0.25    # 单只上限
```
